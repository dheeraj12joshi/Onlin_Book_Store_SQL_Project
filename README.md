# 📚 Online Book Store SQL Project

## 📌 Project Overview

This project demonstrates SQL concepts by analyzing the data of an online book store using PostgreSQL. It includes database creation, table relationships, data querying, joins, aggregate functions, window functions, subqueries, Common Table Expressions (CTEs), and business-oriented SQL problems.

The project simulates real-world bookstore operations such as customer orders, inventory management, sales analysis, and revenue calculation.

---

## 🛠️ Technologies Used

- PostgreSQL
- pgAdmin / PostgreSQL

---

## 📂 Database Schema

The project consists of three tables:

- **Books** – Stores book details such as title, author, genre, price, and stock.
- **Customer** – Stores customer information including name, email, city, and country.
- **Orders** – Stores order details including customer, book, quantity, order date, and total amount.

---

## 📊 SQL Concepts Covered

- SELECT Statements
- WHERE, ORDER BY, GROUP BY, HAVING
- Aggregate Functions (SUM, AVG, COUNT, MAX, MIN)
- INNER JOIN & LEFT JOIN
- Subqueries
- Common Table Expressions (CTEs)
- Window Functions
- Inventory Analysis
- Revenue Analysis
- Customer & Sales Analytics

## 📈 Business Problems Solved

- Total books sold by genre
- Average book price by genre
- Customers with multiple orders
- Most frequently ordered book
- Top expensive books by genre
- Total quantity sold by author
- Customer spending analysis
- Highest spending customer
- Remaining stock after fulfilling orders
- Revenue calculations
- Inventory analysis
